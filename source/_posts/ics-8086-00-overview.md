> **ICS 与 8086 汇编复习 · 系列导读**
> [系列目录](/2026/10/30/ics-8086-00-overview/) · [下一篇](/2026/10/30/ics-8086-01-computer-systems-execution/)

这套系列围绕一个问题展开：高级语言中的数据和操作，怎样变成处理器真正执行的指令？阅读顺序先建立数据表示的规则，再用 8086 学会跟踪指令和内存，最后进入 IA-32 的 C 程序分析与可执行文件生成、运行。

正文共 16 篇，每篇都有概念讲解、逐步算例、易错点和三道自测，共 48 道自测题。内容面向系统复习，阅读与练习重点围绕概念、计算、程序跟踪和边界条件展开。

## 两套实验环境的边界

| 项目 | 8086 汇编部分 | ICS 机器级分析部分 |
| --- | --- | --- |
| 主要平台 | 8086 实模式 DOS | IA-32、Linux、GCC；局部对比 x86-64 |
| 汇编写法 | Intel/MASM，目的操作数在前 | GNU AT&T，通常源操作数在前 |
| 地址分析 | 段值乘16再加16位偏移 | 依据相应执行模式和 ABI 分析 |
| 常见工具 | DOSBox、MASM、LINK、DEBUG | GCC、目标文件及反汇编工具 |
| 输入输出示例 | DOS `INT 21H` | C 运行库与相应操作系统机制 |

学习两部分时，应先读每篇标明的平台。8086 没有 EAX、FS、GS 和 IA-32 比例变址；Windows 宿主机内运行 DOSBox，也不意味着正在编写 Win32 API 汇编程序。

## 资料覆盖与引用方式

本系列围绕计算机系统基础与8086汇编课程的知识主线展开。汇编材料含第1—5章课件、首次实验课课件、上机实验文档和 DEBUG 命令文档；ICS 材料含系统概述、数据表示、指令系统、程序表示、链接与加载五份课件。所用11份课件合计964张幻灯片。

汇编第1章以指令集和语言翻译为入口，把汇编定位为连接程序与机器的桥梁，并强调通过读写程序和上机调试建立时间、空间与系统意识。这一导论贯穿正文01和10，原课件可定位至《汇编语言 第1章.ppt》第4、8—9、12—13、26页。

每篇末尾列出对应文件和实际幻灯片序号。实验文档页码可能随排版变化，可结合实验名或命令名定位相应内容。第五份 ICS 课件虽有部分封面编号问题，仍按文件名中的第五章引用。

文章将原课件内容重新组织为讲解，例题和程序多为重写。发现会影响理解的错误时，在相关篇目或速查附录中给出正确规则。涉及指令语义、语言规则和ABI的细节，同时提供相应官方参考。

可从本文目录进入各篇，也可按文末导航顺序阅读。代码与命令需在文中指定的环境中验证；列出的预期结果均应结合位宽、平台和初始状态理解。
